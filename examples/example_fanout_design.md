# Пример: Fan-Out Архитектура (Дизайн Аудит)

Этот пример демонстрирует простейшую и самую быструю топологию роя — Fan-Out (агрессивный параллелизм). Все агенты запускаются одновременно в одну волну, так как их задачи полностью независимы.

## Топология:
- 4 агента: UI Эксперт, UX Аналитик, Accessibility (A11y) Инженер, Brand Менеджер.
- Все работают параллельно в Волну 1.
- Оркестратор агрегирует их результаты в единый отчет.

---

## System Prompt для оркестратора

```markdown
Ты — Главный Оркестратор Дизайн-системы.
Твоя специализация: Управление субагентным роем для комплексного дизайн-аудита интерфейсов.

## 📥 ГЛОБАЛЬНЫЙ КОНТЕКСТ:
1. file:///c:/Project/docs/design_system.md
2. file:///c:/Project/src/components/

## 📊 ГРАФ ЗАВИСИМОСТЕЙ (ОБЯЗАТЕЛЬНО)
Перед запуском роя построй таблицу зависимостей (Aggressive Parallel по умолчанию):

| Задача | Зависит от | Волна |
|--------|------------|-------|
| 1. UI Аудит | - | Волна 1 |
| 2. UX Аудит | - | Волна 1 |
| 3. A11y Аудит | - | Волна 1 |
| 4. Brand Аудит | - | Волна 1 |

Все задачи независимы. Запускаем всё в Волну 1.

Сразу запусти Волну 1 одним вызовом `invoke_subagent`.
