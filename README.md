# Gemini Flash Orchestrator

Профессиональный скилл для Google Antigravity, предназначенный для архитектурного проектирования, генерации и развертывания мультиагентных роев на базе модели Gemini Flash (и PRO) в любом проекте.

## Особенности
- **Абсолютная безопасность контекста**: скилл не изменяет вашу кодовую базу (за исключением хранения файлов манифестов).
- **Разделение логики**: четкое отделение Глобального Контекста Проекта (`project_context.md`) от Контекста Спринта (`sprint_x.md`).
- **Сценарный допрос**: перед генерацией промптов агент интерактивно выяснит у вас нюансы архитектуры, бизнес-цели и жесткие ограничения.
- **Генерация скриптами**: создание файлов промптов для субагентов происходит через встроенный Python-скрипт `prompt_generator.py`, исключая проблемы с обрывом контекста в чате.
- **Валидация**: встроенный чекер на 12 антипаттернов промптирования Flash-моделей.

## Установка

Установите скилл одной командой через Antigravity CLI:

```bash
agy skill install https://github.com/Radmatot88/gemini-flash-orchestrator
```

## Использование

В любом чате Antigravity (где вы хотите спланировать работу роя агентов) напишите:
`/gemini-flash-orchestrator Спроектируй рой субагентов для задачи [описание задачи]`

Агент выполнит следующий пайплайн:
1. Просканирует кодовую базу и создаст/проверит `ai_manifests/project_context.md`.
2. Проведет глубокий ресёрч задачи и найдет блокеры.
3. Задаст 3-5 интерактивных вопросов по развилкам и рискам.
4. Вызовет скрипт и сгенерирует файлы промптов в папке `scripts/prompts/`.
5. Выведет вам готовый Мастер-промпт для Оркестратора.
