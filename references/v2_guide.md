# 🧬 Gemini Flash Orchestrator v2: Deep Context Architecture

Этот документ описывает архитектурный переход к версии 2.0 и новую парадигму сбора контекста.

## 🔴 Проблема v1 (Поверхностное сканирование и Галлюцинации)
В первой версии Оркестратор пытался самостоятельно извлечь данные проекта, опираясь на жестко заданный список файлов (`README.md`, `package.json`, `INDEX.md`). 
**Последствия:** Если проектная документация (например, Карточка Проекта) имела нестандартное имя или лежала глубоко в папках, Оркестратор её не находил. Будучи LLM, он пытался "заполнить пробелы" в шаблоне `project_context.md`, генерируя выдуманные имена врачей, метрики или фреймворки.

## 🟢 Решение v2 (Skill-to-Skill Delegation)
В версии 2.0 Оркестратор **лишен права самостоятельно извлекать сырые данные из файлов**. Вместо этого он использует концепцию делегирования другому специализированному мета-скиллу — `project-architect-extractor`.

### Как работает пайплайн v2:

1. **Точка входа:** При запуске Оркестратор ищет только один файл — `_project_card/card.json`. Это стандартизированный, жесткий JSON, который невозможно галлюцинировать.
2. **Автономный Рой (Delegation):** Если JSON отсутствует, Оркестратор не просит пользователя "сделай карточку". Он запускает процесс `invoke_subagent`, передавая управление скиллу `project-architect-extractor`. Рой Экстрактора проводит глубокий реверс-инжиниринг всей папки и формирует `card.json`.
3. **Трансляция (Data Formatting):** Получив JSON, Оркестратор превращается в строгого парсера. Он переносит данные из JSON в `ai_manifests/project_context.md`:
   - `identity.domain` и `team` ➔ **Бизнес-контекст**
   - `tech_stack` ➔ **Технический стек**
   - `inventory` ➔ **Архитектурная карта**
   - `risk_register` и `gaps` ➔ **Жесткие ограничения**

### 🚫 Anti-Hallucination Protocol
Оркестратор работает в режиме строгого копирования. Введена директива:
> "Если массив `team` пуст — пиши 'Команда не специфицирована'. Категорически запрещается додумывать данные для красоты текста."

## Итог
Архитектура v2 обеспечивает **100% достоверность контекста**, делая фундамент для генерации промптов субагентов пуленепробиваемым, при этом процесс остается полностью автономным для конечного пользователя.
